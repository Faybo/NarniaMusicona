# Narnia Crib Music 🎵

Uma plataforma de streaming de música exclusiva para amigos compartilharem suas músicas originais.

## Tecnologias Utilizadas

- Next.js 13
- React
- TypeScript
- Supabase (Autenticação e Banco de Dados)
- Tailwind CSS
- React Hook Form
- Zustand

## Funcionalidades

- 🎵 Upload de músicas em formato MP3
- 🖼️ Upload de imagens para capa das músicas
- 🎨 Interface moderna e responsiva
- 🎧 Player de música completo
- ❤️ Sistema de curtidas
- 🔍 Busca de músicas
- 📱 Design responsivo

## Como Usar

1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/narnia-music.git
```

2. Instale as dependências
```bash
npm install
```

3. Configure as variáveis de ambiente
Crie um arquivo `.env` na raiz do projeto e adicione:
```env
NEXT_PUBLIC_SUPABASE_URL=sua_url_do_supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY=sua_chave_anonima_do_supabase
```

4. Inicie o servidor de desenvolvimento
```bash
npm run dev
```

5. Acesse http://localhost:3000
